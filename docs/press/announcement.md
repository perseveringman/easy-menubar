# Bar · 状态栏

让菜单栏，留给常用的图标。

装的 Mac 应用越来越多，菜单栏也越来越挤。Bar 把图标放进一张原生列表：找到所属应用，隐藏偶尔才用的图标，需要时再显示回来。

它支持搜索、逐项恢复和全部显示，设置保存在本机，退出 Bar 后仍然保留。不需要账户或联网，也不需要屏幕录制权限。

Bar 适用于 macOS 26 及更新系统。它依赖应用保存的状态栏偏好，所以并非所有图标都能隐藏；系统图标仍由 macOS 设置管理。辅助功能授权可选，用来读取图标名称、位置和当前状态。

1.0.0 已提供通用 ZIP 与 DMG，并完成 Developer ID 签名与 Apple 公证。
