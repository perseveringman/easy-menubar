Bar · 状态栏 1.0.0

让菜单栏，留给常用的图标。

- 原生列表管理第三方菜单栏图标，支持搜索、逐项隐藏与恢复、全部显示。
- 记住隐藏项目，退出 Bar 后保留设置，应用未运行时也能保存修改。
- 明确标出等待重启、系统管理与不可写项目；普通应用手动重启前先确认。
- 本地运行，无账户、无统计与上传代码；辅助功能授权可选。

系统要求：macOS 26+。通用包包含 Apple Silicon 与 Intel，实际运行验收在 Apple Silicon Mac 上完成。

下载 DMG，将 Bar.app 拖入 Applications。ZIP 可用于直接解压安装。两个包均使用 Developer ID 签名并通过 Apple 公证，包含已装订的公证票据；校验文件用于检查下载完整性。

已知限制：并非所有图标都可隐藏；目标应用须保存可写的状态栏偏好，普通应用可能需要重启。系统图标请在系统设置中调整，避免与其他菜单栏管理器同时运行。卸载前先使用“全部显示”并按提示重启所属应用。
