Bar 安装与恢复

系统要求：macOS 26 或更新版本。通用二进制包含 Apple Silicon 与 Intel。
1. 将 Bar.app 拖入 Applications 文件夹。
2. 打开 Bar，点击图标右侧的隐藏按钮。菜单栏工具可能会正常退出并重新打开；请先结束正在进行的任务。
3. 普通应用的设置在下次启动时生效。列表中的重启按钮会先让你确认。
4. 辅助功能授权是可选的，用来读取图标名称与实际位置。App 数据授权用来读取沙盒应用的偏好设置。
5. 恢复：点击“全部显示”，再按提示重启相关应用。退出 Bar 不会撤销已保存的隐藏设置。
6. 卸载前先“全部显示”并检查菜单栏，再退出 Bar，将 Bar.app 移到废纸篓。
