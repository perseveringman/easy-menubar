# 隐私说明

Bar 在你的 Mac 本机工作。当前版本不包含登录、广告、分析统计、崩溃上报或网络请求代码，也不会上传菜单栏信息。

当前 1.1 开发版枚举运行中的应用和当前 Space 的菜单栏窗口，以实际窗口建立列表；窗口标识、几何位置、AX 名称与 identifier 只在本机用于匹配图标，不上传。历史偏好独立用于旧设置恢复和当前仍保留的旧写入路径，不作为图标存在的证明。

Bar 也读取用户 Preferences 目录中的 plist，以查找 `NSStatusItem` 设置。只有点击“查找旧设置”后，才尝试读取已知或运行中的沙盒应用对应的偏好文件；该选择仅在本次运行有效。程序只提取状态栏设置；不扫描沙盒中的文档、聊天记录或媒体文件。偏好文件会在内存中解析，缓存只保留状态栏相关键，不复制到 Bar 的数据库或上传。受保护读取使用短时辅助进程，超过三秒即结束该辅助进程，不结束所属应用。

点击隐藏或显示时，Bar 通过 macOS 的 `defaults` 工具写入目标应用的状态栏可见性偏好。Bar 在自己的 UserDefaults 中记住被隐藏项目的应用标识、名称和状态栏项名称，以便应用退出后仍可恢复。待生效修改还保存目标显示状态、所属进程标识及启动时间，以便重新打开 Bar 后继续提示。

当前开发版引导辅助功能授权后再进入实时列表，用于读取状态栏图标名称、identifier 与位置。未授权时显示连接引导。App 数据权限由 macOS 管理，仅在按需查找旧版沙盒设置时可能出现提示；拒绝不妨碍当前窗口枚举。Bar 不会自行修改系统隐私授权，也不要求屏幕录制权限。

退出 Bar 后，目标应用的可见性偏好继续保留。卸载前请先从更多菜单恢复旧版隐藏设置，并按提示重新启动所属应用。已发布 1.0.0 的行为与说明以该版本标签内的文档为准。
