# 隐私说明

Bar 在你的 Mac 本机工作。当前版本不包含登录、广告、分析统计、崩溃上报或网络请求代码，也不会上传菜单栏信息。

Bar 枚举运行中的应用，并读取用户 Preferences 目录中的 plist，以查找 `NSStatusItem` 图标设置。对于已知或运行中的沙盒应用，也会尝试读取对应容器中的偏好文件。程序只提取状态栏设置；不扫描沙盒中的文档、聊天记录或媒体文件。为实现扫描，偏好文件会在内存中解析，但不复制到 Bar 的数据库或上传。

点击隐藏或显示时，Bar 通过 macOS 的 `defaults` 工具写入目标应用的状态栏可见性偏好。Bar 在自己的 UserDefaults 中记住被隐藏项目的应用标识、名称和状态栏项名称，以便应用退出后仍可恢复。

辅助功能权限为可选项，仅用于读取状态栏图标名称、位置及可见状态。未授权时，列表可能不完整，状态主要基于保存的偏好。App 数据权限由 macOS 管理，读取沙盒容器时可能出现提示；拒绝后相应项目可能无法被列出或修改。Bar 不会修改系统隐私授权。

退出 Bar 后，目标应用的可见性偏好继续保留。卸载前请先点击“全部显示”，并按提示重新启动所属应用。
